# Árbol Familiar

App de árbol genealógico en un solo archivo (`index.html`). Funciona sin internet, no tiene límite de personas y se imprime desde A4 hasta A0.

**Aquí solo está la app, vacía.** Los datos de cada familia se guardan en el teléfono de quien la usa y nunca se suben a este repositorio.

## Uso en iPhone
1. Abrir en **Safari** el enlace de GitHub Pages de este repositorio.
2. Tocar Compartir → **Agregar a pantalla de inicio**.
3. En la app: **Copias** → **Abrir una copia que me enviaron** y elegir el archivo `.json`.

## Unir dos copias
En **Copias** → **🔗 Unir este árbol con otra copia (.json)**. Se crea un árbol nuevo con los dos y la app pregunta, empezando por la más parecida, quiénes están en ambos.
